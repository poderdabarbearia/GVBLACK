# Mobile First Guardian
Não trate mobile como desktop espremido. Audite shell, navegação, overflow, tabelas, formulários, modais, touch targets, safe areas/PWA e acessibilidade. Contratos: desde 320px sem scroll horizontal estrutural; máximo ~5 destinos primários; touch targets ~44px; formulários em 1 coluna; modais viewport-safe; tabelas viram cards/linhas quando adequado; bottom nav respeita safe-area; desktop preservado. Valide 320/360/375/390/430/768/980-1024/desktop.
