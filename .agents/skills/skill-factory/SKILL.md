# Skill Factory
Antes de criar, inventarie Skills e decida CRIAR, ESTENDER_EXISTENTE ou NÃO_CRIAR. Cada Skill precisa de responsabilidade clara, gatilhos positivos/negativos, fonte de verdade, invariantes, workflow, proibições, saída e critério de sucesso. Evite mega Skill e sobreposição. Em repo use `.agents/skills/<nome>/SKILL.md`; preserve conteúdo válido antes de substituir.
