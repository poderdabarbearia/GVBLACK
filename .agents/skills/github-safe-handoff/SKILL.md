# GitHub Safe Handoff
Confirme owner/repo, base, branch, SHA e instruções. Para mudanças sensíveis prefira branch curta → delta mínimo → validação → diff → PR → revalidação → merge autorizado. Nunca force-push/reset destrutivo nem reescreva histórico publicado. Preserve mudanças concorrentes, não envie secrets e diferencie commit/merge/migration/deploy/produção.
