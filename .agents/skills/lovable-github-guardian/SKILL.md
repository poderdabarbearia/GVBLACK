# Lovable GitHub Guardian
Separe sempre: código GitHub; branch/commit/PR; sync Lovable; Cloud; banco/schema; migration versionada/aplicada; Edge versionada/deployada; secrets/env; preview; deploy; runtime. Trabalhe GitHub-first quando o código está versionado. GitHub atualizado não prova sync; sync não prova deploy; migration no repo não prova aplicação.
