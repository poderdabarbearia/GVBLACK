# Multi-Tenant Guardian
Identifique tenant canônico, memberships, roles e resolução server-side. IDs do browser nunca são autorização. Teste SELECT/INSERT/UPDATE/DELETE A→A e A→B, RPC/SECURITY DEFINER, Edge, Storage, Realtime, workers, WhatsApp e billing. SECURITY DEFINER valida auth, membership, role, tenant e ownership com search_path/grants seguros.
